# @core/components — Input Field Wrappers
READ-ONLY reference. Adaptasi ke module, jangan import langsung.

## Komponen
- `AppTextField.vue` — text input standar project
- `AppSelect.vue` — select/dropdown standar
- `AppCombobox.vue` — combobox dengan autocomplete
- `AppDateTimePicker.vue` — date/time picker

## Penggunaan
Lihat props dan event yang dipakai, adaptasi ke komponen module kamu.
Gunakan `color="primary"` untuk konsistensi Ecogreen theme.
